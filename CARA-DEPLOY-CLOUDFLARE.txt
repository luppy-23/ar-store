AR STORE — HAPUS GAMEPASS/LIMITED + OWNER PANEL

1) Upload seluruh isi ZIP ke ROOT repository GitHub (index.html, assets, functions, schema.sql).
2) Buat Cloudflare D1 database bernama ar-store-db.
3) Jalankan isi schema.sql pada D1 Console.
4) Cloudflare Pages -> project -> Settings -> Functions -> D1 database bindings:
   Variable name: DB
   D1 database: ar-store-db
5) Set environment variables/secrets di Pages Settings -> Variables and Secrets:
   OWNER_PASSWORD = password rahasia milik owner (buat sendiri, panjang dan unik)
   OWNER_SESSION_SECRET = random secret panjang (minimal 32 karakter)
6) Redeploy project.
7) Website menampilkan tombol Owner. Login memakai OWNER_PASSWORD.
8) Owner dapat mengubah status transaksi: Menunggu Pembayaran, Pembayaran Diterima, Diproses, Selesai, Dibatalkan.
9) Pembeli cek status dari kode transaksi melalui backend D1, lintas perangkat.

PENTING:
- Jangan menaruh password owner di HTML atau repository.
- D1 binding dan kedua secret harus disetel sebelum fitur transaksi/owner aktif.
- Login menggunakan cookie HttpOnly, Secure, SameSite=Strict dengan sesi 8 jam.
- Pembayaran QRIS/e-wallet belum otomatis diverifikasi; owner mengubah status setelah mengecek pembayaran.
- Harga paket dan nominal manual perlu dikunci/validasi ulang di server sebelum produksi; endpoint contoh ini mengandalkan nilai harga dari katalog frontend.
